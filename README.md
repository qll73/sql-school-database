# مشروع قاعدة بيانات مدرسة التميز (Oracle SQL)

مشروع متكامل لإدارة بيانات مدرسة باستخدام أوراكل SQL.

## محتويات المشروع:
- **الجداول الأساسية:** الجداول وتحديد المفاتيح والقيود (`students`, `teachers`, `courses`).
- **العلاقات الربط:** جداول العلاقات (`student_courses`, `student_teachers`) والربط بواسطة `Foreign Keys`.
- **العناصر الإضافية:** إنشاء `Procedure` لعرض معلومات الطلاب، و`View` للربط بين المعلمين والمواد، و`Index` لتحسين أداء البحث.
